# Setup for duceysane10/duceysane10

1. Create or open the public GitHub repository `duceysane10/duceysane10`.
2. Upload `README.md` to the repository root.
3. Upload `.github/workflows/snake.yml` and `.github/workflows/profile-3d.yml`, preserving their directories.
4. In repository Settings > Actions > General > Workflow permissions, select Read and write permissions, then Save.
5. In Actions, manually run `Generate contribution snake` and `GitHub Profile 3D Contributions` once.
6. After both successful runs, refresh your profile. Automatic scheduled updates follow daily.

Notes:
- The terminal graphic, live GitHub stats, and language badges rely on third-party image endpoints and may be temporarily unavailable.
- The terminal API graphic uses your public GitHub profile details.
- The 3D graphic won't appear until its workflow commits the SVG into the repository.
- The snake graphic won't appear until the snake workflow publishes the `output` branch.
- Pinned repositories, achievements and the native contribution timeline are controlled through GitHub, not README markdown.
- Somalia rank comes from committers.top and may display unranked; it is not an official GitHub ranking.
- You can update technology tags and the CaawiyeIVR description if you want to specify more concrete implementation details.
